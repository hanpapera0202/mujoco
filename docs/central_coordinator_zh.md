# 集中式雙手臂協調器

本專案採單一集中式協調器。Robot A 與 Robot B 是對等執行端；協調器持有兩台手臂、皮帶、物件與共享碰撞空間的全域狀態，並在每次事件或控制週期統一派工。

## 演算法分層

1. 快篩：工件狀態、Deadline、可達性、手臂忙碌狀態、可抓取候選。
2. 全域指派：依 Deadline、抓取成功率與移動成本為所有 arm-object pair 打分。
3. 時空預約：每個候選必須預約 `shared_zone` 與進出時間區間；時間區間重疊即排除。
4. 低層規劃：只有通過快篩與預約的候選才交給 IK / MoveIt / 局部避碰器。
5. 回饋：抓取失敗、軌跡延遲或新工件到達時立即重新決策。

Fuzzy 不是安全核心。未來可將其加入 `grasp_success` 或 candidate score 的估計，但 Deadline、可達性與 reservation 都維持硬限制。
