# 版本與推送規範

本專案使用語意化版本 `MAJOR.MINOR.PATCH`：

- `MAJOR`：改變控制架構、資料格式或場景契約，造成舊實驗結果不可直接比較。
- `MINOR`：新增可獨立使用的演算法、場景能力或控制台功能，且保留既有流程。
- `PATCH`：修正模型、參數、碰撞、視覺或文件，不改變公開契約。

每次推送須使用下列提交格式：

`vX.Y.Z: <scope> - <簡短英文摘要>`

其中 `<scope>` 可為 `sim`、`planner`、`grasp`、`model`、`dashboard`、`docs` 或 `build`。發布版本時必須建立並推送同名 Git tag，例如 `v0.2.0`。

目前版本 `0.12.1` 延續 BC-JSP、中央交接預備與雙速率閉迴路 IK，並加入執行器效能節流與並行 handoff 接近。安全待命位仍以完整未來路徑與 10 cm 警戒盒驗證；開始接近後改以 1 秒短視窗檢查真正 MuJoCo 幾何接觸，讓兩臂保持平行權限，不再把共同走廊警戒盒淨空當成右臂開始移動的必要條件。追蹤 IK 採 12.5 Hz、12 次 warm-start 迭代與 8 mm 位移門檻；安全預測採 50 Hz，實體 MuJoCo 接觸仍維持每個控制步檢查。
