# 版本與推送規範

本專案使用語意化版本 `MAJOR.MINOR.PATCH`：

- `MAJOR`：改變控制架構、資料格式或場景契約，造成舊實驗結果不可直接比較。
- `MINOR`：新增可獨立使用的演算法、場景能力或控制台功能，且保留既有流程。
- `PATCH`：修正模型、參數、碰撞、視覺或文件，不改變公開契約。

每次推送須使用下列提交格式：

`vX.Y.Z: <scope> - <簡短英文摘要>`

其中 `<scope>` 可為 `sim`、`planner`、`grasp`、`model`、`dashboard`、`docs` 或 `build`。發布版本時必須建立並推送同名 Git tag，例如 `v0.2.0`。

目前版本 `0.6.0` 新增 BC-JSP 貝式集中聯合策略規劃：CSPR 快篩後比較 3 x 3 聯合路徑、以 Beta-Bernoulli 信念計算期望效用，並在 GUI 顯示選擇結果。碰撞警戒外擴距離可在 `0.02–0.30 m` 調整，預設為 10 cm且不改變實體碰撞盒。`PLACE-01` 的 10 件 100% 與 10 cm 預設下更高雙臂重疊運動比例仍列為尚未完成。
